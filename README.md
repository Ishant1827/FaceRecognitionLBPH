📌 Face Recognition System

A Face Recognition System built using Python and OpenCV that detects and recognizes human faces in real-time. This project uses computer vision and machine learning techniques to identify individuals through a webcam.

🚀 Features
🎯 Real-time face detection
🧠 Face recognition using trained data
📸 Capture and store face images
🆔 Identify and label known faces
⚡ Fast and efficient performance
🛠️ Technologies Used
Python 🐍
OpenCV
NumPy
Face Recognition (ML-based encoding)
📂 Project Workflow
Collect face images
Train the model with dataset
Start webcam for live detection
Recognize and match faces
Display name of the person
